I build data pipelines with PySpark and Databricks, moving data from the Lakehouse to the platforms that consume it. Today I work on a customer relationship and collections data team, where I help develop incremental pipelines over Delta Lake tables, integrations with Salesforce Data Cloud, and the CI/CD that takes them from dev to production.

I came to data engineering through CWI Crescer, CWI Software's professional acceleration program, where I went through the Java backend, QA, and data engineering tracks. That path shaped how I work: I care about code that is versioned, tested, and easy to maintain, whether it's an API or a pipeline.

Before tech, I spent years working with 3D modeling in digital dentistry, a field where precision isn't optional. I'm currently studying Systems Analysis and Development at PUCPR.
