Construo pipelines de dados com PySpark e Databricks, levando dados do Lakehouse até as plataformas que os consomem. Hoje atuo em um time de dados de relacionamento com cliente e cobrança, onde participo do desenvolvimento de pipelines incrementais sobre tabelas Delta Lake, de integrações com o Salesforce Data Cloud e do CI/CD que leva tudo isso de dev até produção.

Cheguei à engenharia de dados pelo CWI Crescer, programa de aceleração profissional da CWI Software, onde passei pelas trilhas de backend em Java, QA e engenharia de dados. Esse caminho moldou meu jeito de trabalhar: me importo com código versionado, testado e fácil de manter, seja uma API ou um pipeline.

Antes da tecnologia, trabalhei por anos com modelagem 3D na odontologia digital, uma área em que precisão não é opcional. Atualmente curso Análise e Desenvolvimento de Sistemas na PUCPR.
